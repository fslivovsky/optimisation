The epigraph

epi f = { (x, t) : x ∈ dom f,  t ≥ f(x) }.   f is convex exactly when epi f is a convex set.

segment inside epi f segment leaves epi f

Drag the two points anywhere in the shaded region. For a convex function the segment between them never leaves it; for a nonconvex one you can always find a pair where it does. With both points on the graph the segment is a chord, which is the definition of convexity itself.

Drag to rotate, scroll or pinch to zoom. The epigraph is everything above the surface; it is cut off at a fixed height so it can be drawn.
