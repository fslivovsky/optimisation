Simplex tableau stepper

Run the Simplex method on a tableau. Click a negative entry in row 0 to choose the entering variable. The ratio test then picks the pivot row (or you pick it yourself), and Pivot carries out the row operations. Row 0 holds minus the cost and the reduced costs. The other rows hold the values of the basic variables and B−1A.

Row operations of the last pivot

    The picture shows the feasible region in the (x1, x2) plane. The dark dot is the current basic feasible solution, the orange line the path so far, and the arrow the basic direction of the selected column.
